# CLUTCH 아키텍처 문서

이 폴더는 CLUTCH의 전체 시스템 구성과 주요 데이터 흐름을 설명한다.

## 기준 문서

- [시스템 전체 구성](system-overview.md): 클라이언트, 애플리케이션, 데이터 저장소,
  외부 연동, 모니터링 구성과 핵심 처리 흐름

패키지 배치와 계층 책임은 [패키지 구조](../04-conventions/package-structure.md), 기능별
비즈니스 규칙은 [`02-domain/`](../02-domain/), 중요한 기술 선택의 이유는
[`03-decisions/`](../03-decisions/)에서 관리한다.

아키텍처 문서에는 시스템을 한눈에 이해하는 데 필요한 내용만 두고, 세부 규칙은 각 기준
문서에 작성한 뒤 링크한다.
