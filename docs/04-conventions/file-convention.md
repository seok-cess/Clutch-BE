# 파일 인코딩과 줄바꿈 규칙

## 기본 형식

- 텍스트 파일의 문자 인코딩은 UTF-8을 사용한다.
- 텍스트 파일의 기본 줄바꿈 형식은 CRLF로 통일한다.
- Git 체크아웃과 정규화 기준은 저장소 루트의 `.gitattributes`다.
- IDE와 에디터의 생성·저장 기준은 저장소 루트의 `.editorconfig`다.

## LF 예외

Linux와 macOS에서 직접 실행되는 다음 파일은 CRLF 사용 시 실행 오류가 발생할 수 있으므로 LF를 유지한다.

- Gradle Wrapper 실행 파일 `gradlew`
- `*.sh`
- `*.bash`
- `*.zsh`

Windows 실행 파일인 `*.bat`, `*.cmd`, `*.ps1`은 CRLF를 사용한다. JAR 등 바이너리 파일은 줄바꿈 변환 대상에서 제외한다.

## 작업 규칙

- 에디터의 개별 설정 대신 `.editorconfig`와 `.gitattributes`를 우선한다.
- 새 텍스트 파일에도 같은 규칙을 적용한다.
- 기능 변경 없이 줄바꿈만 바뀌는 대규모 diff를 만들지 않는다.
- 기존 파일의 줄바꿈을 일괄 정규화해야 한다면 별도 작업으로 수행한다.
