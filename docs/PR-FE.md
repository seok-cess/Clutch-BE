## 개요

일정 화면에 월별 필터를 추가한다.

백엔드가 과거 페이지까지 수집하면서 일정이 320건이 됐고, 전 시즌이 한 화면에
날짜순으로 늘어서 원하는 경기를 찾기 어려웠다.

## 변경 사항

- `ScheduleList` 상단에 월 탭 추가. 일정에 존재하는 월만 최신순으로 보여준다
- 기본 선택 — 진행 중인 경기가 있으면 그 달, 없으면 다가오는 경기의 달,
  둘 다 없으면 가장 최근 달
- 사용자가 탭을 고른 뒤에는 일정이 갱신돼도 선택을 덮어쓰지 않는다
- 월이 하나뿐이면 탭을 렌더링하지 않는다
- 스타일은 기존 헤어라인 톤에 맞춰 테두리·색상만 사용 (발광·그림자 없음)
