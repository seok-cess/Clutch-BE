# 외부 경기 피드의 지연된 종료 상태 트러블슈팅

## 문제 상황

LoL Esports 외부 소스는 실제 경기가 끝난 뒤에도 매치를 한동안 `inProgress`로 제공할 수 있다.
세트가 종료됐는데도 라이브 목록에 남아 화면이 밴픽 또는 대기 상태처럼 보이고, 배팅 정산에
사용할 승자도 즉시 확정할 수 없는 문제가 있었다.

## 원인

외부 소스의 종료 관련 값은 같은 시점에 갱신되지 않는다.

- livestats의 `gameState=finished`는 세트 종료를 비교적 빠르게 알린다.
- 일정·매치 데이터의 `gameWins`는 세트 종료보다 늦게 증가할 수 있다.
- 외부 매치 상태도 실제 다전제 종료보다 늦게 `completed`로 바뀔 수 있다.
- 활성 세트가 보이지 않는 것만으로는 세트 사이 대기와 매치 종료를 구분할 수 없다.

## 해결

세트 종료, 승자 확정과 매치 종료를 하나의 상태로 처리하지 않았다.

1. livestats의 `finished`는 세트가 종료됐다는 화면 표시와 종료 시각에 사용한다.
2. 팀별 `gameWins` 증가가 확인된 경우에만 세트 승자와 스코어를 확정한다.
3. 어느 팀이든 `bestOf`의 과반 승수에 도달하면 외부 매치 상태와 관계없이 내부 매치를
   종료로 판정한다.
4. 종료된 매치는 설정된 보존 시간 동안 라이브 목록에 유지한 뒤 제거한다.
5. API는 피드 종료 여부, 확정된 세트 승자, 매치 상태와 최종 승리 팀을 분리해 제공한다.

배팅 정산과 결과 기반 쿠폰 처리는 빠른 종료 신호가 아니라 확정된 승자를 사용한다.

## 검증

- Bo3에서 1승이면 `inProgress`, 2승에 도달하면 `completed`로 판정한다.
- Bo5에서 3승에 도달한 경우만 매치를 종료한다.
- `gameWins`가 아직 증가하지 않았으면 세트 종료 신호가 있어도 승자를 추정하지 않는다.
- 최초 종료 시각이 후속 폴링에서 초기화되지 않는지 확인한다.
- 종료 매치가 보존 시간 뒤 라이브 목록에서 제거되는지 검증한다.

## 남은 한계

외부 소스가 `gameWins`를 장시간 갱신하지 않으면 승자 확정과 배팅 정산도 지연된다. 이 경우
승자를 추정해 정산하지 않고 공식 결과 재조회 흐름을 유지한다.
