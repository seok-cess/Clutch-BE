# 시청 포인트 지급 규칙

## 범위

이 문서는 경기 시청 시간에 따른 포인트 지급 규칙을 설명한다.

## 지급 주기와 금액

- 유효 시청 시간 5분마다 100포인트를 받을 수 있다.
- 5분이 누적되면 포인트 수령 버튼을 표시한다.
- 사용자가 버튼을 누르기 전까지 버튼을 계속 표시한다.
- 버튼이 표시된 동안에는 시청 시간을 추가로 누적하지 않는다.
- 사용자가 버튼을 누르면 100포인트를 지급한다.
- 지급이 완료되면 누적 시청 시간을 0으로 초기화하고 다음 5분 누적을 시작한다.

## 상태 흐름

```text
시청 시작
→ 유효 시청 시간 누적
→ 5분 도달
→ 포인트 수령 버튼 표시 및 시간 누적 정지
→ 사용자 버튼 클릭
→ 100포인트 지급
→ 누적 시간 0으로 초기화
→ 다음 주기 시작
```

## 동시 경기 처리 범위

- 여러 경기가 동시에 진행될 때 두 경기에서 포인트를 동시에 적립하거나 지급받는 기능은 구현 범위에 포함하지 않는다.
- 동시 경기별로 별도의 시청 시간을 누적하는 기능도 지원하지 않는다.
- AI는 별도 요구사항 없이 다중 경기 포인트 적립 기능을 추가하지 않는다.
