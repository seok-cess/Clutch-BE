# 승패 배팅 규칙

## 현재 구현 범위

- 현재 우선 구현하는 배팅 방식은 경기 승패 맞추기다.
- 모든 경기에 승패 배팅 기회를 한 번씩 제공한다.
- 사용자는 승리 또는 패배 결과에 배팅한다.
- 첫 용 맞추기와 퍼블 대상 맞추기는 현재 구현 범위에 포함하지 않는다.

## 배팅 포인트

- 최소 배팅 금액은 1,000포인트다.
- 최대 배팅 금액은 100,000포인트다.
- 배팅 금액은 최소·최대 범위를 모두 포함한다.
- 적중하면 배팅 금액의 2배를 정산한다.
- 적중하지 못하면 배팅한 포인트를 몰수한다.
- 배팅 참여 인원에 따른 동적 배당률은 현재 적용하지 않는다.

## 배팅 가능 시간

배팅 가능 시간 산정에는 조사된 평균 20분을 기준으로 사용한다. 조사 범위는 최소 19분에서 최대 40분이다.

### 첫 번째 경기

- 공식 일정 시작 20분 전에 배팅을 연다.
- 공식 일정 시작 후 1분에 배팅을 닫는다.

```text
공식 일정 - 20분 ≤ 배팅 가능 시간 < 공식 일정 + 1분
```

### 두 번째 경기부터

- 이전 경기가 끝나는 시점에 배팅을 연다.
- 배팅을 연 시점부터 20분 동안 배팅을 받는다.

```text
이전 경기 종료 시각 ≤ 배팅 가능 시간 < 이전 경기 종료 시각 + 20분
```

여기서 "이전 경기 종료 시각"은 피드가 세트 종료를 알린 시각(livestats `gameState=finished`)을
기준으로 한다. 소스의 세트 상태(`completed`)는 실제 종료보다 약 5분 늦으므로, 그 값을 쓰면
배팅 창이 그만큼 밀려 다음 세트가 시작된 뒤에 닫힌다. 조사된 세트 간격이 평균 20분대라
5분의 지연을 흡수할 여유가 없다.

세부 근거는 `docs/domain/match-set-result.md`를 따른다.

## 향후 검토 대상

다음 항목은 아이디어로만 유지하며 현재 규칙으로 구현하지 않는다.

- 첫 용 맞추기
- 퍼블 대상 맞추기
- 배팅 참여 인원에 따른 배당률 조정
