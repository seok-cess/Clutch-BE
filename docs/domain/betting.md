# 승패 배팅 도메인 규칙

## 범위

배팅 대상은 한 매치의 각 세트 승리 팀이다. 한 이벤트에서는 정확히 두 참가 팀 중 하나를 선택한다.
배팅 금액은 1,000포인트 이상 100,000포인트 이하다.

## 이벤트 상태

| 상태 | 의미 |
|---|---|
| `OPEN` | 배팅 등록을 받을 수 있다. |
| `CLOSED` | 등록은 끝났고 승자 확정 또는 정산을 기다린다. |
| `SETTLED` | 승자 확정과 배팅 정산이 끝났다. |
| `CANCELLED` | 세트가 진행되지 않아 배팅금을 환불한다. |

- 사용자는 같은 배팅 이벤트에 한 번만 배팅할 수 있다.
- 배팅 등록 시 포인트를 즉시 차감하고 `STAKE` 원장을 기록한다.
- 세트가 취소되면 모든 `PLACED` 배팅을 `REFUNDED`로 전환하고 원금을 전액 돌려준다.

## 풀배당 정산

정산은 이벤트가 `CLOSED` 상태이고 세트 승자가 확정된 뒤에만 수행한다.

- 총 풀은 해당 이벤트의 모든 `PLACED` 배팅금 합이다.
- 운영 수수료는 총 풀의 10%를 소수점 버림해 계산한다.
- 배당 풀은 총 풀에서 운영 수수료를 뺀 금액이다.
- 적중자는 자신이 건 포인트 비율에 따라 배당 풀을 나눈다. 지급액에는 원금 반환분이 포함된다.
- 실패 배팅은 `LOST`로 전환하고 포인트를 지급하지 않는다.
- 적중 배팅은 `WON`으로 전환하고 계산된 지급액만큼 포인트를 증가시킨 뒤 `PAYOUT` 원장을 기록한다.
- 개별 비례 배분에서 소수점을 버려 남은 포인트는 운영 수수료에 포함한다.
- 실제 승리 팀을 선택한 배팅이 하나도 없으면 모든 배팅을 `LOST`로 처리하고 총 풀 전액을 운영 측에 남긴다.

```text
운영 수수료 = 총 풀 × 10%
배당 풀 = 총 풀 - 운영 수수료
개별 적중 지급액 = 배당 풀 × 내 배팅금 ÷ 적중 배팅금 합
```

예를 들어 A팀 적중 배팅이 1,000p와 2,000p, B팀 실패 배팅이 7,000p이면 총 풀은 10,000p다.
수수료 1,000p를 제외한 9,000p를 적중 배팅금 비율대로 나누므로 A팀 적중자에게 각각 3,000p와
6,000p를 지급한다.

## 멱등성

- 정산과 환불은 이벤트 행과 `PLACED` 사용자 배팅을 잠근 하나의 데이터베이스 transaction에서 처리한다.
- 이미 `SETTLED` 상태인 이벤트는 다시 정산하지 않는다.
- 사용자 배팅별 `PAYOUT` 또는 `REFUND` 원장은 한 번만 기록한다.
